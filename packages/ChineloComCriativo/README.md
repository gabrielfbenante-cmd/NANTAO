# ChineloComCriativo

Chinelo arremessável que voa reto na direção da mira e explode ao bater em algo ou ao chegar no alcance.
Inclui o **Modo Criativo**, para testes: o host recebe chinelos de graça.

| Tecla | Ação |
|---|---|
| Clique esquerdo | Arremessar |
| G / E | Largar / pegar |
| F6 | Entregar ou recuperar um chinelo (host, com o criativo ligado) |
| F7 | Ligar ou desligar o criativo |

- Todos na lobby precisam ter a mesma versão.
- Com o criativo ligado e `UsarSaveDeTeste = true`, o host usa o save separado **ChineloCriativoTeste**. Para uma partida de verdade, desligue o criativo (F7 ou `Criativo / Ativado = false`) **antes** de hospedar.
- Precisa de `HideManagerGameObject = true` em `BepInEx/config/BepInEx.cfg`.
