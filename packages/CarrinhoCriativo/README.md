# CarrinhoCriativo

Carrinho de supermercado com cesto para até 8 itens e lugar para 1 passageiro. Quem simula o carrinho é o host.

| Tecla | Ação |
|---|---|
| F5 | Chamar o carrinho (host) |
| E | Empurrar / soltar (olhando para o carrinho) |
| R | Guardar no cesto o item da mão |
| T | Descarregar o cesto |
| V | Entrar ou sair como passageiro |

- Todos na lobby precisam ter a mesma versão.
- O carrinho **não é salvo** com a nave: descarregue antes de sair.
- Precisa de `HideManagerGameObject = true` em `BepInEx/config/BepInEx.cfg`.
